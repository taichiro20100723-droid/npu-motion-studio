# NPU AI Video

**画像を動かして、変身させる。ロボット→犬、廃墟→都市、ラフ→完成品。すべてPC内で。**

[English](README.md) · [設計](docs/architecture.md) · [実測](docs/benchmarks.md) · [Intel応募資料](docs/intel-innovator-application.md)

![巨大ロボットが本物の柴犬へ変身する実動画](examples/robot-to-dog/robot-to-dog.gif)

一般的な画像→動画AIは、1枚の絵を少し動かすものが中心です。NPU AI Videoは**最初のAと
最後のBを自分で決め、その間にある「ありえない変化」をAIで描きます。** 画像を2枚入れ、
「装甲が毛に変わり、機械の脚が犬の足になる」と一文書いて、作成ボタンを押すだけです。

MVの場面転換、ショート動画、作品のビフォーアフター、製品コンセプト、ミーム、奇妙な映像実験に
使えます。クラウドへの画像送信、順番待ち、複雑なノード操作はありません。上のロボット→犬も、
このアプリが1台のノートPCで実際に作った動画です。

## 特徴

- 既定は強力な **A→Bモード**。先頭=A、最後=Bを固定します。
- Aの縦横比を維持し、Bを無理に引き伸ばしません。
- 日本語をローカル翻訳し、ダンス・建築・走行・変形などを各NPU画像へ反映します。
- 英語プロンプトにも直接対応します。
- CPU=文章理解、NPU=画像生成、Arc GPU=画像化と補間、Quick Sync=MP4書き出し。
- 日本語／Englishを画面右上で切り替えられます。
- 入力画像や文章を外部サービスへ送りません。
- 2枚・一文・作成ボタンだけ。難しい機器設定は画面の裏側へ隠しています。
- 画面の候補ボタンから動きの一言を選べるので、プロンプトを考えなくても最初の1本を試せます。
- 最初に **小（8枚）・中（12枚）・大（20枚）** を選び、その品質で一度に生成します。迷ったら中がおすすめです。
- Motion Brushで、赤=強く動かす、青=固定、矢印=動く方向を指定できます。
- NPUが次を描いている間に、完成区間をArc GPUへ渡して並列に補間します。
- **AI文字モード**では、文字をシートに並べてからNPUへ渡し、文字の形の変化をAIが自然に描きます。
- 変化用プロンプトは任意です。空欄でも「文字が別の記号へ変わる」動きを内部で自動指定します。

[Motion Brushを使ったロボット→犬の実動画](examples/motion-brush/robot-to-dog-motion-brush.mp4)では、
ロボットを赤く塗り、右向き矢印を指定し、そのまま12枚の高品質版へ引き継いでいます。

## こんな映像を作れます

- ロボット→犬、人物→怪物、昼→夜など、まったく違う姿への変身
- ラフスケッチ→完成品、古い建物→未来都市など、制作過程の見せ方
- MV・SNS動画・ゲーム映像に使える、短く強い場面転換
- 正解を決めずに試す、変で面白いローカルAI実験

## 使い方

1. 初回だけ `setup_windows.bat` をダブルクリックします。
2. 普段は `run_windows.bat` をダブルクリックします。
3. A・最初の画像とB・最後の画像を選びます。
4. 「ロボットの装甲が毛になり、本物の柴犬へ変身する」のように、**途中で何が起こるか**を書きます。
5. 品質を「小」「中」「大」から選びます（迷ったら「中」）。
6. 「動画を作る」を押します。選んだ品質で最初から最後まで生成します。

### AIで文字を変化させる

上部の「AI文字を変化させる」を選び、元の文字（例: `NPU MOTION`）と雰囲気のヒントを選びます。
「文字シートを作る」で元の文字を写真のようなシートに並べます。そのシートを入力にして、NPUが
各文字を自然な別形状へ変化させます。変化の文章は空欄でも作成できます。必要なら、変化の文章を
追加して「光になる」「液体になる」などの方向だけ指定できます。
手元の文字シート画像も使えます。フリー素材、自作画像、別の画像生成ツールで作った画像を
クリックまたはドロップすると、その画像をそのままNPUへ渡します。権利や利用条件は素材ごとに
確認してください。

画像AIや補間ツールは初回セットアップ時に取得され、GitHubにはモデル本体を含めません。

## 実測

Core Ultra 7 258V / Intel AI Boost / Arc 140V / OpenVINO 2025.4.1。

| 内容 | 合計 |
|---|---:|
| A→B、ダイナミック、8枚、4秒 / 96コマ | **11.61秒** |
| ロボット→犬、高品質、12枚、5秒 / 120コマ | **20.69秒** |
| 1枚、すばやく、4枚、3秒 / 47コマ | **5.80秒** |
| 高品質、12枚、建築、5秒 | **15.39秒** |
| v0.5 ロボット→犬、4枚の高速確認、4秒 | **2.83秒**（旧方式の参考値） |
| v0.5 同じ入力を12枚で生成、4秒 | **18.05秒** |

1台でのウォーム状態の実測であり、すべての入力やPCへの保証値ではありません。

## 正直な限界

- AI画像間で顔・服・車体の細部が少し変わることがあります。
- まったく違う物への変身は途中がシュールになることがあり、部品構造も工学的に正しいとは限りません。
- 複数人の格闘や、道具を正確に持ち替える動作はまだ苦手です。
