# Glyph Stage sample

This sample uses the default source text `NPU MOTION` with the `CYBER` mood hint.
The app first creates one local character sheet for the NPU:

- `SVG` — the editable source character sheet passed to the image-to-image stage

To make the same sample in the running app, choose **Transform text with AI**, enter
`NPU MOTION`, select **CYBER**, and press **Make character sheet**. Leave the motion prompt
blank and press **Create**: the NPU supplies the character transformation automatically.

You can replace the generated sheet by dropping a PNG, JPEG, or WebP character-sheet image into
the optional image area. This is useful for a public-domain/free-to-use sheet, a photo you made,
or a sheet generated in another image tool; the image is used as the NPU input without a programmatic
glyph replacement table.
