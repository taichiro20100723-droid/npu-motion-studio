# Glyph Stage sample

This sample uses the default source text `NPU MOTION` with the `CYBER` style.
The app creates three local assets from the same deterministic glyph identity:

- `TXT` — copyable transformed characters
- `SVG` — animated, editable vector artwork
- `FONT` — a small TTF that maps the original source characters to the custom glyph shapes

To make the same sample in the running app, choose **Animate strange glyphs**, enter
`NPU MOTION`, select **CYBER**, and press **Make assets**. Press **Create** to animate the
same artwork with the local NPU pipeline.
